维护规则（硬性，新增技能必须照做）

本目录的索引、预览图与技能包必须始终一致。任何一项缺失都算「没做完」。

  1. 新增网页设计技能时，必须同时更新本索引。只加技能不改索引 = 未完成，不得推送。
  2. 每项技能必须有 preview.gif，放在技能包根目录。规格：宽 ≤ 320px、≤ 20fps、 文件 ≤ 800KB、首帧亮度 > 200（黑屏开场的图不能当缩略图）。
  3. 预览图要展示该技能最综合的效果，不是随便一帧截图。交互类技能要录到真实操作过程。
  4. 索引不手改。改完技能后执行 python3 tools/build_web_index.py 重新生成， 它会同步 previews/<技能目录名>.gif。
  5. 提交前必须过一致性检查： python3 tools/check_web_index.py。 它比对「索引里列的技能」与「roster 里的分类」、逐张核对 GIF 的 md5 是否与包内一致、 尺寸是否超限。不通过会以非 0 退出。
  6. 技能改名或移除时，索引与 previews/ 里的旧图必须一起清掉， 不允许留下孤儿文件。
检查命令不通过时，不要推仓库：先修到通过为止。
python3 tools/build_web_index.py && python3 tools/check_web_index.py
数据来自 roster.json（category=网页设计）与各技能 manifest.json； 预览图取自各技能包 preview.gif。
